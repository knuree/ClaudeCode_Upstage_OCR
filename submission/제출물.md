# 제출물 (산출물 ①, ②)

- **사용 도구**: Claude Code(AI 코딩 도구)로 구현, 순수 HTML/CSS/JavaScript 정적 페이지 + Python 표준 라이브러리(csv·pathlib·collections), 배포는 (배포 서비스명 입력).
- **구현 메모 1**: CSV 데이터를 `index.html`에 직접 내장해 서버 없이 동작하게 했고, 카드뉴스 4장은 `<img>`로 상단에 임베드했습니다.
- **구현 메모 2**: 검색은 카테고리명·문의기관을 부분 일치로 필터링하고 "결과 N건"은 일치한 서비스 수입니다. 예: "복지"는 카테고리 복지와 문의기관 '보건복지부'에 모두 일치합니다.
- **구현 메모 3**: 대표 문의기관은 카테고리 내 최다 등장 기관이며, 동률이면 가나다순으로 앞선 기관을 택했습니다(웹과 `solution.py`가 동일 규칙).
- **구현 메모 4**: 데이터가 샘플용으로 보입니다(예: 대피소 안내의 문의기관이 국세청). 현실과 맞는지 따로 고치지 않고 그대로 사용했습니다. `solution.py`는 엑셀 호환을 위해 BOM 포함 UTF-8로 저장합니다.
